# 💰 Personal Finance Management Dashboard

A Personal Finance Management Dashboard built using **Python and Streamlit** to track, analyze, and visualize personal financial transactions.

## 📊 Project Overview

This project helps users understand their spending patterns and financial activities through an interactive dashboard.

It includes transaction data processing, data cleaning, category analysis, and interactive visualizations.

## ✨ Features

- 💰 Track personal transactions
- 📊 Analyze income and expenses
- 🏷️ Category-wise transaction analysis
- 📅 Analyze spending over time
- 📈 Interactive charts and visualizations
- 🔍 Transaction filtering
- 🤖 Machine Learning model integration

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Streamlit
- Scikit-learn
- Matplotlib
- Plotly
